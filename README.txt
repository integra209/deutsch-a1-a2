DEUTSCH MEISTER — ОБНОВЛЕНИЕ ДЛЯ GITHUB PAGES

Содержимое архива:
- index.html
- styles.css
- app.js
- manifest.webmanifest
- sw.js

КАК ОБНОВИТЬ САЙТ
1. Открой https://github.com/integra209/deutsch-a1-a2
2. Открой каждый из пяти файлов в корне репозитория.
3. Нажми значок карандаша (Edit this file), замени всё содержимое соответствующим файлом из архива.
4. Нажми Commit changes. Повтори для остальных файлов.
5. Подожди 1–3 минуты и открой https://integra209.github.io/deutsch-a1-a2/.
6. Если отображается старая версия, закрой вкладку и открой сайт заново; на iPhone также можно удалить старую иконку с экрана «Домой» и добавить сайт снова.

ВАЖНО
- Архив не загружен в GitHub автоматически. Файлы нужно заменить вручную.
- Прогресс хранится локально в браузере. Старые данные из предыдущей версии не переносятся автоматически.
- В словаре включено 120 учебных единиц A1–A2 (слова и выражения) по 12 темам.
- Цветовая оценка появляется после 5 последних попыток: зелёный — 0 ошибок, жёлтый — 1–2, красный — 3–5. До пяти попыток показывается нейтральная отметка количества.
- Настоящие фоновые push-напоминания пока не подключены: для них нужен сервер Web Push/VAPID и хранение подписок. GitHub Pages сам по себе не отправляет запланированные уведомления.
