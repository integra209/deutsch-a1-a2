# Deutsch A1–A2 — первая версия

Персональный PWA-тренажёр немецкого языка. Данные занятий хранятся локально в браузере на устройстве (localStorage); аккаунт и серверная база для прогресса не используются.

## Состав
- `index.html` — интерфейс
- `styles.css` — адаптивный дизайн
- `app.js` — уроки, упражнения, проверка ответов и локальный прогресс
- `manifest.webmanifest` — настройки установки PWA
- `sw.js` — офлайн-кэш
- `icons/icon.svg` и `icons/icon-180.png` — иконки

## Запуск
Для проверки откройте `index.html` в браузере. Для установки PWA и работы Service Worker нужен HTTPS-хостинг (или localhost). После размещения на HTTPS откройте адрес в Safari на iPhone → Поделиться → На экран «Домой».

## Приватность
Прогресс хранится в `localStorage` этого браузера. Приложение не загружает внешние шрифты и не отправляет учебные данные на сервер. Не очищайте данные Safari для сайта, если хотите сохранить прогресс. В этой первой версии нет синхронизации между устройствами и отдельной блокировки приложения паролем.
